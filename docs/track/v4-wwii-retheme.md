# v4 — 二战地下智斗游戏重制

## 1. 愿景
将 HHSGame 从奇幻 Roguelike 改造为二战沦陷区地下智斗游戏。主角可选 6 种身份，3 幕剧情，6 种结局。

## 2. 角色背景
| # | 身份 | 特点 |
|---|------|------|
| 1 | 抵抗势力成员 | 擅长潜行、破坏、情报 |
| 2 | 占领军底层军官 | 擅长军事、审讯、资源获取 |
| 3 | 傀儡政权公务员 | 擅长社交、情报、调停 |
| 4 | 沦陷区平民 | 灵活、可加入任意阵营 |
| 5 | 流亡士兵 | 战斗经验丰富，无固定立场 |
| 6 | 匪徒 | 混乱邪恶，独立行动 |

## 3. 地图区域
- 中央城区（政治/经济中心）
- 占领军指挥部（北部）
- 盟军前线（南部）
- 抵抗军营地（东部山区）
- 匪徒占据区（西部废弃工业区）
- 居民区（中部）
- 宗教/中立组织区域

## 4. 三幕剧情
- **第一幕**：身份建立、阵营初识、基础任务
- **第二幕**：阵营对立升级、关键抉择、情报战
- **第三幕**：最终战役、结局分支

## 5. 武器系统
- 手枪（M1911/鲁格/托卡列夫）
- 步枪（莫辛-纳甘/毛瑟98/李-恩菲尔德）
- 冲锋枪（MP40/汤普森/PPSh-41）
- 手榴弹/燃烧瓶
- 近战武器（匕首/棍棒/工兵铲）

## 6. 敌对势力
- 占领军士兵/军官
- 盖世太保特务
- 协作者/线人
- 匪徒帮派
- 叛变的抵抗者

## 7. 结局
1. 占领军胜利（反抗失败）
2. 傀儡政权独立（左右逢源）
3. 抵抗成功（摧毁指挥部）
4. 平民支援胜利
5. 流亡士兵独立获益
6. 匪徒占领中央城市
